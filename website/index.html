01 / CAPABILITIES

Clear boundaries. Useful evidence.

01 / SOURCE

Local project auditing

Inspects selected source and configuration files, with bounded traversal, credential-indicator redaction and .env hygiene checks.

02 / WEB

HTTP configuration

One HEAD request to an approved endpoint. No automatic redirects, crawling, authentication attempts or exploit payloads.

03 / NMAP

Service discovery

Uses an independently installed Nmap. Bounded TCP connect scan, fixed arguments, XML parsing, best-effort service metadata.

04 / REPORTS

Portable results

Self-contained HTML, reviewable Markdown and structured JSON. Open TCP services are classified as informational observations.

05 / CLI

Professional terminal

Interactive monochrome-inspired presentation, dependency diagnostics, readable progress and a plain-output fallback for scripts.

06 / WINDOWS

Guided setup

Accept/Decline terms, install progress, optional PATH integration, desktop shortcut, user-level installation and clean uninstall.

03 / INSTALLATION

Transparent setup. Explicit choice.

Get the verified release

Download the Windows installer and SHA256SUMS file from the GitHub prerelease, verify its checksum.

Review and accept terms

The installer includes a detailed acceptable-use agreement with distinct Accept / Decline controls. Declining stops installation.

Choose your installation options

Select the destination, optional desktop shortcut and user PATH integration; the setup shows actual installation progress.

Install Nmap independently if needed

SecuBrain links to the official Nmap download page. Nmap/Npcap are not bundled due to separate licensing rights.

Open SecuBrain and run doctor

Check the environment, then audit a local project or a separately authorized HTTP endpoint.
