# SecuBrain download page

`index.html` is a small, privacy-preserving, standalone product and download landing page. It requires no build process, tracking, external stylesheets, third-party scripts or remote fonts. The primary installer link points to the GitHub prerelease for version 0.4.0.

**Deployment:** this file is version-controlled but is not automatically published as GitHub Pages. A repository maintainer must explicitly enable/configure the hosting destination and deploy it. Direct GitHub source view is not a live web deployment.

The browser cannot observe progress for a cross-origin GitHub download, so this site **does not fake a progress bar**. The actual Windows installation progress is displayed by the installer.

See `docs/windows-installer.md` for full user installation instructions.
