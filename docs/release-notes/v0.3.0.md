# SecuBrain v0.3.0 — Nmap inventory engine

This prerelease focuses on a practical Nmap-powered network inventory, not visual redesign or autonomous penetration testing.

## Added

- `secubrain nmap --target HOST --authorized` command and `scan --target HOST --nmap --authorized` equivalent.
- Three explicit TCP profiles: **quick** (~100 common), **standard** (~1000), **full** (all 65,535 ports).
- Opt-in UDP scanning, OS fingerprinting and Nmap default NSE scripts; privileged features may require administrator/root/Npcap.
- Structured host inventory: addresses, names, state/reason, uptime, OS guesses, TCP/UDP ports, service/product/version, CPE, NSE metadata, aggregated closed/filtered state counts.
- Expanded JSON canonical report and concise HTML/Markdown port summaries; informational-only port findings.
- Clear failures and nonzero exit status for requested-but-unavailable/failed Nmap scans, with partial report retention.
- Native Nmap loopback check in Ubuntu CI, gated before the Windows installer build/release.

## Updated

- Documentation and scope validation, including explicit one-host target requirement and no shell argument pass-through.
- Windows installer updated to 0.3.0 with Nmap detection guidance; tracks only PATH entries added by setup.
- Automated Go unit/integration tests and fake-Nmap executable fixture.

## Important limitations

Nmap and Npcap must be installed **separately**, under their own license terms. No binary or driver is redistributed by SecuBrain. The **full** profile means all TCP ports; it is not all Nmap functionality, a vulnerability scanner or a penetration test. No AI, exploitation, brute force, arbitrary NSE script path or multi-target network scan is included.

This unsigned prototype is provided for authorized systems only. Findings require human review. Refer to `legal/INSTALLER-TERMS.txt` and `SECURITY.md`.
