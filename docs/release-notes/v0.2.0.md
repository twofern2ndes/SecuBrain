# SecuBrain 0.2.0 — Windows Setup & Nmap Adapter

**Prototype prerelease — not production-certified.**

## Added

- Professional interactive CLI with TTY-aware ANSI styling, subtle startup animation and plain-text fallback.
- `doctor`/`tools` command to discover a user-installed Nmap and report its location/version.
- Opt-in Nmap TCP connect and light service detection using fixed, low-rate arguments, timeouts and XML parsing.
- Structured Nmap scan status and open TCP service observations in HTML, Markdown and JSON reports.
- Windows x64 installer based on Inno Setup, with welcome, lengthy installation terms and explicit Accept/Decline, installation progress, optional desktop shortcut and user PATH integration, documentation and uninstall support.
- A dedicated Nmap wizard page and official download link; **Nmap and Npcap are NOT bundled** because of third-party license restrictions.
- Extended automated tests and a CI workflow for Windows installer build, installation smoke test and SHA-256 checksum.
- International English-language installation, Nmap and release documentation.

## Existing functionality

- Bounded local source/config inspections, credential pattern warnings, HTTP header checks and three report formats.
- No AI runtime or API keys, no exploit/credential attacks, no crawling.

## Limitations

- Nmap is an independent installation, not an embedded component.
- No Windows Authenticode signature or independent certification.
- A complete report does not certify a system's security; service labels are best-effort observations.
- Automated Nmap adapter tests use a fixture, not a public or production network target.
