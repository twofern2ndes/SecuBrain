# SecuBrain v0.4.0 — Neural Terminal Experience

This prerelease focuses **exclusively on terminal ergonomics**. The existing
Nmap integration and deterministic audit engine are intentionally unchanged.

## New in v0.4.0

- Original, animated brain/neural-connection visualization in a responsive
  full-screen terminal dashboard (Windows and Linux terminal input support).
- Live command activity, asynchronous audit execution and cancellable progress.
- Keyboard editing, command history, built-in completion and compact layouts.
- No new runtime dependencies or model downloads: implemented in Go.
- Safe fallback for pipes, CI, dumb terminals and unsupported console modes.
- Unit tests for animation, layout, keyboard handling, input boundaries,
  terminal-control sanitization, real audit integration and race detection.
- Reproducible Linux PTY smoke test proving terminal-state restoration.

## No changes to security scope

Nmap and Npcap remain separately installed, according to their licenses. The
network scanner still accepts only one authorized target. The default NSE
scripts, UDP/OS modes and other Nmap options remain explicit opt-ins. No AI,
autonomous exploitation, credential attacks or mass-target scans are added.

## Windows installer

The prerelease build includes a Windows x64 graphical setup with a license
acceptance screen, optional PATH entry and uninstaller. It installs the new
SecuBrain CLI, **not** Nmap/Npcap. The binary is not digitally signed.
