1. DESCRIPTION AND PURPOSE

SecuBrain is a security auditing prototype and developer-oriented CLI.
The project is designed to support learning, internal code review,
defensive engineering, authorized security assessments, and professional
review of systems by their owners or authorized administrators. It performs
bounded, deterministic checks and produces locally stored reports.
SecuBrain is not an autonomous exploitation framework, does not contain
an artificial intelligence engine, and does not attempt to replace a
qualified human security assessment.

You are solely responsible for ensuring that you are legally entitled to

Do not use this software to access, disrupt, damage, enumerate, inspect,

Permission for a web address does not automatically authorize every host,

3. NETWORK AND SERVICE CHECKS

Network scanning generates real network traffic. Even scans configured
with low packet rates can trigger intrusion-detection controls, audit
alerts, rate limits, performance impacts or unintended behavior on
fragile equipment. Always schedule tests, inform the responsible system
owner, use an approved change window where appropriate, and establish
procedures for stopping a scan safely. SecuBrain's --authorized option
records the operator's assertion; it does not independently verify legal
permission or ownership.

6. INSTALLATION, PATH CHANGES AND UNINSTALLATION

The setup program installs SecuBrain in a directory selected by the user.
If selected, it can add that directory to your user PATH for convenient
command-line access, and it can create Start Menu or desktop shortcuts.
It does not request administrator privileges for the default user-level
installation. The uninstaller removes SecuBrain files installed by Setup
and the specific SecuBrain PATH entry when present. Separately installed
Nmap, Npcap, and files the operator has created are not part of SecuBrain's
uninstallation process.

7. OUTPUT, DATA AND PRIVACY

SecuBrain can read local files in the directory you provide and may write
security findings, filesystem paths, URL hostnames, timestamps, service
information and potential indicators to local reports. Reports are not
automatically sent to a cloud AI provider. Protect reports with appropriate
filesystem permissions, access controls and retention policies. Although
SecuBrain attempts to avoid disclosing detected credentials, no automated
redaction is perfect. Review reports before sharing or publishing them.

8. NO SECURITY GUARANTEE

SecuBrain does not perform a comprehensive penetration test. A successful
scan, the absence of findings, or a report labeled "completed" does not
establish that a system is secure, compliant, hardened, or free from
vulnerabilities. Service detection and classifications may be erroneous.
Human review and independent validation remain necessary.
